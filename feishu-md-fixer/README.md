# NOAH Markdown 助手（飞书粘贴一键清洗）

在粘贴到飞书前，一键清洗 Markdown：标题升降级、Emoji 处理、去代码块、去掉引用标记但保留正文、去分割线、数字 Emoji 转有序列表、折叠空行等。支持从网页/飞书复制 HTML 后自动转 Markdown 并清洗。复制到剪贴板时，围栏外的空行会压成单换行，代码块内部的空行保留；表格和嵌套列表会写成飞书能识别的 HTML。

在线演示：<https://yuanmenghe.github.io/Demo/feishu-md-fixer/>

## 2026-11-02 使用上的调整

- 打开页面不再先被指南挡住。顶部留一条可关闭的提示，完整步骤仍从「使用指南」进入。
- 主按钮收成「读取并清洗」和「复制到飞书」。
- 粘贴和规则变更可以撤销。没改过正文时，规则按最初粘贴的原文重算。
- 模板说明改到模板名称的悬停提示里，不再铺在页头。
- 代码块只保留语言，去掉 Meta。
- 行首序号分成三级：`一、` 是 1.，`（1）` 缩进一级，`①` 再缩进一级。中文数字支持到「一百零一」。
- 紧挨着的跳号写成 `21．`，避免编辑器把它收成第 2 条；复制到飞书时还原成真正的列表。
- 复制结果带上链接、斜体、待办框和图片。技术文档模板默认保留图片。
- 浏览器标题改为「NOAH Markdown 助手」。

## 2026-11-01 修复

- **复制到飞书**：Markdown 表格改为 `<table>`，嵌套列表保持层级；跳号的有序列表用 `value` 保留原序号。
- **序号规范化**：只匹配行首，并且只把顿号 `、` 当成序号标点。`二十一、` 得到 `21.`。句子里的「第一，」「版本（1）」「见①项」不再被改掉。
- **引用**：勾选「删除引用格式」后只去掉 `>`，引用里的正文留下。
- **代码块**：去掉 Markdown 转义、以及复制前压缩空行时，都跳过代码围栏。表格单元格里的 `\|` 不再被还原成裸 `|`。
- **链接**：`[**文档**](url)` 会保留「文档」，网址里的 `\:` 会还原成 `:`。
- **标题升降级**：空行后的 `---`，以及标题下面单独一行的 `---`，继续当作分割线，不再被收成标题。
- **空行选项**：选 0 会去掉块与块之间的空行；代码块内部不受影响。
- **HTML 转入**：同一行里 `td` / `th` 按文档顺序读取；嵌套列表会缩进到父项下面。
- **说明文字**：默认模板不再写「会自动把标题降一级」。序号说明改为全部转成 `1. 2. 3.`。超过 H6 的标题继续用更多 `#`，复制时输出 `h7` 及以上。
- **撤销**：历史记录改成纯状态更新，避免开发模式下同一步被记两次。

## 快速开始

- **本地运行**：`npm install` → `npm run dev`，浏览器打开提示的地址（如 http://localhost:5173）。
- **本地构建后打开**：双击 `start.bat`（会先执行 `npm run build`，再启动本地预览服务并打开 `http://127.0.0.1:4173/`）。
- **云环境部署**：见下方「部署」章节。

首次打开网站时会显示**使用指南**，也可随时点击页头「使用指南」查看。

## 部署（公司云 / Docker）

- 构建镜像：在项目根目录执行  
  `docker build -t <镜像名>:<版本> .`
- 运行：容器内 Nginx 监听 80，提供静态站点；健康检查路径为 `/health`。
- 本地验证示例：`docker run --rm -p 8080:80 <镜像名>:<版本>`，浏览器打开 `http://localhost:8080/`。
- 域名与 HTTPS：由统一网关 / Ingress 配置。

项目根目录已提供 `Dockerfile`、`.dockerignore` 与 `nginx.conf`。镜像内也兼容 `/feishu-md-fixer/` 子路径访问。

## 用户指南（网站内）

该功能为纯前端（localStorage + 弹层），不影响构建与部署流程。

打开网站后：

1. **首次访问**：会自动弹出使用指南，可按步骤操作；勾选「不再自动显示」后关闭，下次不再自动弹出。
2. **随时查看**：点击页头 **「使用指南」** 可再次打开指南。

指南内容包含：一键读取剪贴板、粘贴弹窗、右侧规则与模板、复制到飞书等说明。
